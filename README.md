# dual-layer info filter · 双层信息过滤

> 一个很窄的工具：**在细读之前，先扫一眼这篇外部材料有没有夹带私货，以及它夹在哪。**
>
> ⛔ 它不是过滤器，不给你打分，也不替你判断。**它只报信号。**

---

## 为什么需要它

"回一手源核验"能回答一个问题：**这份材料有没有编？**

但它不回答另一个问题：**核完之后，这份材料还能不能信？**

因为有两件事是**独立的**：

| | 问的是 |
|:--|:--|
| **第一件** | 它是谁？有没有利益关系？有没有导流动作？ |
| **第二件** | 它说的这件事，有没有可核的一手支撑？ |

**这两件事经常不一致：**

- **引用真，不等于动机纯。** 论文是真的，导流也是真的。
- **动机有私，不等于结论假。** 一个卖货的人说"水往低处流"，水照样往低处流。

所以一把尺子必然二选一地犯错。**两把尺子，才能同时拿到这两条事实。**

---

## 第二个洞见：位置也是信息

> **同一个词，出现在正文中间，和只出现在文末，风险完全不是一回事。**

举例：**「咨询」**

- 在正文里，它是普通词，行业分析里到处都是
- **只在结尾第一次冒出来，它就是转化动作**

`scan.py` 因此**单独扫文末窗口**（默认最后 15%），并且**只报「正文里完全没有、只在文末出现」的词**。

**这个做法出奇地干净** —— 因为**正经文章的词，不会只在结尾才第一次出现。**

---

## 用法

无依赖，Python 3.8+。

```bash
python3 scripts/scan.py article.txt
python3 scripts/scan.py article.txt --json
python3 scripts/scan.py article.txt --tail-ratio 0.20
```

输出：

```
【带货 / 交易】✅ 无
【私域导流】✅ 无
【线下就医导流】⚠️ 命中 1 项：预约咨询

【⭐ 文末独有信号】⚠️ 这些词正文里完全没有、只在文末出现：
    预约、咨询
```

作为库用：

```python
from scan import scan_text

r = scan_text(open("article.txt", encoding="utf-8").read())
if r["tail_only_hits"]:
    print("文末有独有信号：", r["tail_only_hits"])
```

## ⚠️ 它不做什么（请一定读完）

1. ⛔ **它不是过滤器。** 别因为"扫过没报警"就放心。
   **正确用法是：它扫完 + 你读到结尾，两条都过才算过。**
2. ⛔ **它不判对错。** 命中一个词只意味着"这里有个东西，你自己看"。
3. ⛔ **它不评可信度。** 它跟"这篇是否可信"是两个维度 —— 见上文"两把尺子"。
4. ⚠️ **它会漏报，也会误报。** 词表是可解释的经验判据，不是模型。
5. ⚠️ **已知残留误报**：切文末窗口时会切进正文末段。这是已知问题，不是"没发现"。

---

## 词表纪律（想改词表请先看这段）

* ⛔ **只放语用上很少正当出现的词。**
  「门诊」「医院」「就诊」「购买」在正当科普与行业分析里到处都是，
  放进强词表会让误报淹没信号。
* ⛔ **通用编辑部尾巴不算信号。** 「合作或投稿请私信联系」「点赞在看转发」
  这类**任何**公众号文末都有 —— 它们是噪音，已被 `TAIL_EXEMPT` 剥离。
* ⭐ **加词之前先回测**：确认它能抓到正样本，且不误伤正经文。
