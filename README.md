## 先确定一个判据

**知识库的价值，取决于哪一件事：是"存了多少"，还是"每一条能不能回溯"。**

* 如果答案是**前者** —— **一个灌内容的爬虫就够了。**
* 如果答案是**后者** —— **这件事的性质就变了：做的不是内容收集，而是证据管理。**

⭐ 这五个方法**只对后者有意义**。

---

## 五本各防什么

| 方法 | 它防什么 |
|:--|:--|
| **一、引用驱动验证** | 把**转述**当事实 |
| **二、系列化读取** | 把**抽样**当全貌 |
| **三、延伸阅读成图** | 把**堆料**当知识 |
| **四、持续检查机制** | 把**中断**当结束 |
| **五、双层信息过滤** | 把"**引用是真的**"当成"**可以放心用**" |

**共同点**：

> **把判断从"依赖临场记忆"搬到"机械约束"上。**

---

## 三十秒版

| 方法 | 必做动作 | 判据 | 失败信号 |
|:--|:--|:--|:--|
| **一、引用驱动验证** | 回一手核**四件**；分级与"未核"写进档 | 能否指出"**哪些话不作引用依据**" | 档里只有结论，**没有等级** |
| **二、系列化读取** | 先拉全系列；默认 10 篇上限；补账落文件 | **三个计数**（总／取回／通读）齐全 | 出现"已读完"却**给不出三个数** |
| **三、延伸阅读成图** | 索引**归属强制** ＋ 查重三步 | **重复引入率**、来源等级是否保留 | **只有条目数在涨** |
| **四、持续检查机制** | 待办落盘 ＋ 守卫拦截 ＋ 定时审计 | **命中次数是否下降** | 只能回答"**又加了一层**" |
| **五、双层信息过滤** | 位置感知预扫 ＋ 人工读到结尾 | 能否分开说清"**归属**"与"**证据**" | 用动机否事实，或用引用洗白动机 |

## 怎么安装

三种方式，任选一种。**前提：你用支持 `SKILL.md` 的 Agent**（Hermes、Claude Code 等）。

### 方式一：让 Agent 自己装（推荐）

```bash
hermes skills install <owner>/<repo>
```

装完验证：

```
skills_list()            # 确认已注册
skill_view(name='knowledge-agent-playbook')
```

⚠️ **注意**：Agent 按 **SKILL.md frontmatter 里的 `name:`** 注册，⛔ **不是按仓库目录名**。

### 方式二：加为技能源（tap）

```bash
hermes skills tap add <owner>/<repo>
hermes skills search knowledge
```

### 方式三：手工 clone

```bash
git clone --depth 1 https://github.com/<owner>/<repo>.git
cp -r <repo> ~/.hermes/profiles/<your-profile>/skills/<category>/knowledge-agent-playbook
```

⭐ **至少保留** `SKILL.md` ＋ `references/` ＋ `LICENSE`。

### 只想用那个扫描器？

⭐ **不需要装任何东西** —— `scripts/scan.py` **零依赖**，Python 3.8+ 直接跑：

```bash
python3 scripts/scan.py your_article.txt
```

## ⚠️ 边界与限制（请一定读）

⭐ **本文所有数字均为实测记录，不是推演。** 但：

1. ⚠️ **数字出自一台机器、一个使用者，样本量小，不构成普遍结论。**
2. ⚠️ **审计数字由自建脚本统计，没有第三方复核** ——
   它的价值在**前后对比**，不在绝对精确。
3. ⚠️ **这套机制仍在运行中，是"进行时"，不是"完成态"** —— 下一轮翻车同样可能。
4. ⚠️ **词表是经验判据，不是模型**，会有漏报也会误报；
   已知缺陷（位置加权切窗口会切进正文末段）**已在文档中标明，不是"没发现"**。
5. ⛔ **别直接照搬本文的词表** —— 语域不同，误报率会差很多。**改词表请在你自己语料上先回测。**
